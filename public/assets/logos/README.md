# Tool logos

Drop official logo files here to replace the letter badges on the landing page.
Use each company's own published brand assets and follow their usage guidelines.

| File | Tool | Where to get the official asset |
|---|---|---|
| `claude-code.svg` | Claude Code | Anthropic / Claude brand resources |
| `codex.svg` | OpenAI Codex | OpenAI brand guidelines page |
| `cursor.svg` | Cursor | Cursor brand / press kit |
| `opencode.svg` | OpenCode | OpenCode repository or website |
| `gemini.svg` | Gemini CLI | Google Gemini brand resources |
| `github.svg` | GitHub | GitHub logos page (github.com/logos) |

Square SVGs work best (PNG also works if you rename the `src` in `public/index.html`).
If a file is missing, the page keeps showing the letter badge.
