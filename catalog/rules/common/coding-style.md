# Coding Style

- Follow the existing conventions of the file and project before your own preferences.
- Small functions with one responsibility; descriptive names over comments.
- No dead code, commented-out code or debug output in commits.
- Prefer immutable data and pure functions; isolate side effects at the edges.
- Handle errors explicitly; never swallow them.
