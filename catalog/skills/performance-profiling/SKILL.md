# Performance Profiling
1. Reproduce the slow path with a repeatable benchmark or load script.
2. Profile (CPU, memory, I/O, query logs) — do not guess.
3. Fix the biggest measured hotspot only.
4. Re-measure with the same method; report baseline, result and variance.
