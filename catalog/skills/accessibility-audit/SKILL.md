# Accessibility Audit
1. Keyboard-only pass: every control reachable, visible focus, no traps, logical order.
2. Screen-reader pass on key flows: names, roles, states, announcements for errors and async updates.
3. Contrast and zoom (200%) checks; reduced motion respected.
4. Run automated checks (axe/Lighthouse) as a supplement, not a substitute.
5. Report issues with WCAG criterion, impact and fix.
