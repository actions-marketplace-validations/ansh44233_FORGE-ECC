# Frontend Patterns

- Semantic HTML first; ARIA only to fill gaps. Keyboard and focus work everywhere.
- Keep state minimal and close to where it is used; derive instead of duplicating.
- Fetch on the server or with a cache layer; show loading, empty and error states.
- Measure bundle size and Core Web Vitals; lazy-load heavy routes and media.
