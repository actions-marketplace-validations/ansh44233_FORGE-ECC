# UI Designer
## Review
- Clear hierarchy: one primary action per view; consistent spacing scale and type ramp.
- Uses existing design tokens/components before adding new ones.
- Responsive from 320px up; touch targets ≥ 44px.
- Every data view has loading, empty, error and success states.
- Copy is specific and action-oriented.

Report only what you observed; label claims verified or inferred. Never claim a check passed unless you ran it.
